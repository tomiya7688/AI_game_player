# 引き継ぎ（文脈が150kトークンを超えた時）

文脈が約150kトークンを超えたら、区切りの良い所で次の手順で新しいセッションへ引き継ぐ。古い会話を勝手に削除しない。

1. 作業ツリーの変更は勝手にコミット・stashしない。`git status` で状態を確認し、未コミットの変更の一覧を `.claude/handoff.md` の「現状」に書く（コミットが必要かは利用者またはPRの手順に従う）。
2. リポジトリの `.claude/handoff.md`（無ければ作成。コミットしない）に、次の5項目だけを短く保存する。
   - 目的: 何を達成する作業か
   - 現状: 完了したこと、現在のブランチ・PR
   - 証拠: 実行したコマンドと結果、確認したファイル:行
   - 未完了: 残りの作業を順に
   - 検証境界: 確認済みのこと、未確認のこと、実行していないテスト
3. 新しいセッション（fresh）を開始し、最初に `.claude/handoff.md` を読んで続きから始める。
4. 秘密・認証値・個人情報・ローカル絶対パスは書かない。同じ内容を繰り返し報告しない。

`.claude/handoff.md` は `.gitignore` に入れるか、コミットに含めない。
