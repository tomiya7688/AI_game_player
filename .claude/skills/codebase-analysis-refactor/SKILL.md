# Codebase analysis and refactoring

Read project instructions and map relevant structure and data flow with CodeGraph where available, verifying conclusions in source. Identify concrete structural, duplication, performance or maintenance issues using evidence. Limit changes to the requested scope; preserve contracts and behavior, characterize uncertain behavior with meaningful tests, and measure before claiming speed improvements. Use the project's formatter, tests and review rules; report boundaries and unresolved risks.
