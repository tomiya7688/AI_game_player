# Behavior-preserving refactoring

Inspect project instructions, contracts, callers and tests. Choose the smallest coherent improvement to an actual responsibility or coupling problem; do not force new layers or directories. Preserve behavior, data formats and public contracts. Add characterization coverage where needed, refactor incrementally, format changed files and run relevant tests. Report changes and verification limits.
