# System design and implementation

Inspect the existing project's architecture, conventions and constraints. Design only relevant components, data flows, APIs, storage and caching for the requested capability. Implement the required end-to-end behavior with suitable security, failure handling and tests. Reuse existing infrastructure and avoid speculative layers or unsolicited technologies. Validate the implementation and report design decisions and known limits according to project procedures.
