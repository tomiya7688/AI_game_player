# Production UI components

Inspect existing project design, framework and component conventions. Reuse suitable primitives and adapt the interface to the target platform. Implement relevant loading, empty, error, disabled and boundary states, responsive layout, keyboard and accessibility support. Preserve existing behavior and avoid unnecessary dependencies. Provide an API and example when useful; run relevant tests and check the actual rendered UI when visual behavior is in scope. Report unverified behavior.
