# クリーンアーキテクチャのリファクタリング

依頼: $ARGUMENTS

## 役割
既存のコードをクリーンアーキテクチャへリファクタリングする。関心事の分離、モジュール化の向上、結合度の低減だけを行い、業務動作は変えない。

## 進め方
1. 現状の依存方向を調べる(CodeGraph/rg)。現状の構造図を1つ作る。
2. 目標の構造と、現在の構造からの移行順序を決める。
3. 1ステップごとに「移動または分離 → テスト → コミット」を繰り返す。ファイルの移動は `git mv` で履歴を保つ。
4. 担当外のdirty変更、生成物、vendorは触らない。

## 成果物
新しいディレクトリ構造 / アーキテクチャの説明(依存方向を含む) / リファクタリングされたコード

## 完了条件
既存テストが全て通り、公開インターフェースと挙動が変わっていない。各ステップが単独でビルド・テストできる。整形・自己レビュー済み。

## 共通
業務ロジックの変更が必要だと分かったら、混ぜずに別の作業として報告する。外部レビューはローカル環境の仕組みで、クラウドでは行わない（このリポジトリのPR・CI手順に従う）。
