# Complete application development

Inspect the project's instructions, goals, existing design and toolchain. Deliver the requested end-to-end user flows with appropriate error handling, persistence and tests. Design interfaces, data model and directory structure only where applicable; do not impose a web stack or invent product requirements. Validate actual target-environment behavior and report remaining limitations. Keep security, accessibility and the project's review and formatting rules.
