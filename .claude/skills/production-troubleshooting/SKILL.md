# Production troubleshooting

Read project instructions, inspect relevant code and gather bounded evidence. Separate observed symptoms, hypotheses and confirmed causes. Reproduce safely when possible, inspect relevant error and boundary cases, and implement a minimal robust correction within scope. Run the project's formatter and appropriate regression tests. Report the root cause, evidence, fix and remaining uncertainty; avoid claiming reproduction or production verification that was not performed.
