# 独立テストゲーム集の境界と検証

汎用プレイヤーを多様な画面・入力方式で検証するため、#634で既存ゲーム追加commit `a1b7214ca97b4d188f389c0f0efbe876ff67b151`の独立成果物を統合します。旧branchの親にある認識・候補生成の変更は取り込みません。

## 起動と責務

ゲーム一覧・操作・セットアップは[専用README](../tools/test_games/README.md)を参照してください。ゲームは`tools/test_games`の独立環境で起動し、本体と組み合わせる場合はOSの画面・キーボード・マウス境界を使います。通常アプリのPython依存や配布物へGPL fixtureを追加しません。

各ゲームは`games/`内の個別クラスへ責務を分け、元のルール処理を保持します。`ArcadeSession`はメニュー、入力、pause、同じseedでのrestart、終了を所有します。描画・起動に失敗した場合も`finally`でpygameを終了し、例外は呼び出し元へ伝えます。

専用テストは同じGPL境界内の`tools/test_games/tests`で実行します。通常本体のunittestにoptional依存を要求しません。CIは既存のPython qualityジョブから別環境を作り、規則・ライフサイクル試験とSDL dummy描画を行います。

本体wheelを実際にbuildし、110エントリの中にfixtureコードがなく、metadataの依存にpygame/chess/shogiがないことを確認しました。専用ゲーム環境に本体packageはインストールされていません。Windows bundleは既存build scriptの対象を静的照合した範囲で、最終配布物の受入れは未確認です。

## 2026-11-01に確認した範囲

規則・ライフサイクルの52テストが成功しました。全10種類についてpause中の更新・操作抑止、同じseedでの再開始、メニュー復帰・終了を検査し、held controlsの解放と描画・window初期化失敗時のcleanupも検査します。

Linuxの隔離Xvfb display `:97`では、自分で起動したPIDのwindowとfocusを照合し、XTestで通常のOS入力を送る10種類の受入れが成功しました。実入力後の画面はXGetImageで外部から取得しました。

| ゲーム | 実OS入力による効果 | 共通ライフサイクル |
|---|---|---|
| テトリス | 左キーで落下中のブロックが移動 | pause・resume・seedを保つrestart・メニュー・終了を確認 |
| オセロ | 合法マスのクリックで黒石を設置・反転 | 同上 |
| 将棋 | 7g→7fを駒・移動先のクリックで入力 | 同上 |
| チェス | e2→e4を駒・移動先のクリックで入力 | 同上 |
| 五目並べ | 交点のクリックで黒石を設置 | 同上 |
| ローグライク | Spaceの待機でターンを進める | 同上 |
| シューティング | Spaceで弾を発射 | 同上 |
| FPS | 右キーで視点を旋回 | 同上 |
| サンドボックス | 2キーで使用素材を切替 | 同上 |
| ブロック崩し | Spaceでボールを発射 | 同上 |

実画像の自己レビューで将棋の駒がLinuxで同じ欠落glyphへ描画される問題を発見し、Noto CJKの選択と、日本語fontが無い場合の可視ASCII表記を追加しました。修正後も10種類の実入力受入れが成功しています。

`gui_probe.py`は読み取り専用の試験oracleです。通常launcherを同じイベント経路で動かし、pause中の状態不変とrestart直後のseed再現性を評価します。盤面や内部stateをAIのObservation/Decisionへ送信する接続はありません。既定のゲーム起動ではoracle自体が起動しません。

X11の取得・入力は専用テストのPython-Xlib/XTestで実施します。SDL初期化中に仮windowが消失する場合は`BadWindow`として再待機し、所有PIDとfocusが確定したwindowだけを入力対象にします。after-inputのstate、pause前後のhash、restart hash、外部PNGを別々に保存します。

## 証拠の分類と残件

- **Core:** 規則・境界・ライフサイクル試験とSDL描画を確認。
- **Runtime:** 独立プロセスのLinux/X11 window・OS入力・外部captureを確認。本体へのゲーム専用ロジック追加はありません。
- **Real-play:** 上表の実操作シナリオを確認。汎用AIによる自律攻略、成績・汎化精度、全種類の長時間プレイ、実機Windows入力は未検証で、#30/#96へ残します。

同梱CPUは軽量な一手評価で、強い対戦相手としての棋力を保証しません。テトリスは独自wall kick、将棋は入玉宣言・持将棋が未実装、チェスは自動queen昇格・請求可能drawを自動判定します。これらは[元の制約](../tools/test_games/README.md)として保持します。
