# 画面キャプチャ

`WindowsScreenCapture` はWin32 APIで仮想デスクトップをBGRAフレームとして取得する。取得だけを責務とし、OCR・特徴量抽出・OS入力は行わない。Windows以外では明示的にエラーにする。

`ScreenFrame` は幅・高さ・生BGRAバイト列と取得時刻 `captured_at` を持つ。取得時刻はプロセス内で比較する `time.monotonic()` 秒で、実時間・日時ではない。後続の解析Machineはこの値を受け取り、`ScreenObservation`へ変換する。

Win32/GDIのハンドル取得に失敗した場合は明示的なエラーにし、確保済みのDC・Bitmapは失敗経路でも解放する。API依存を注入して、この境界を実入力なしでテストできる。

`window_handle`指定時は対象HWNDを検証する。対象が可視・非最小化で、主画面内に収まり、Z-order上の他の可視ウィンドウにも覆われていないことを確認できた場合のみ、その画面領域を取得する。それ以外はタイムアウト付き`WM_PRINT`で対象アプリ自身に描画を要求し、別ウィンドウの画素を代用しない。描画要求に失敗・タイムアウトした場合は明示的なエラーにする。アプリや描画APIによっては最小化・非表示時やDirectX描画内容を返せない場合があり、取得内容の完全性はまだ保証しない。`window_handle`を省略した場合は従来どおりデスクトップ全体を取得する。

ウィンドウ一覧には可視状態によらずタイトル付きHWNDを含め、同一タイトルの複数ウィンドウもHWND表記で個別に選択できる。HWNDが取得中に失効した場合はフレームを返さず失敗する。
