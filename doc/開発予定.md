# この文書について

AI_GamePlayerにて開発予定のものをまとめる 
AIは設計を軽く書いても良いが深い設計については各自機能説明書.mdを作成して記入すること
表はmdの表機能を利用し、図はmermaidを使用する
実装が完了したら項目を削除すること
優先度について 緊急性が高いものは優先度が高く書かれる、優先度を書いてないものは0である
優先度が低いものはマイナス
変更履歴:doc\ver.md
AI用メモ:doc\Agent.md
仕様書:doc\仕様書.md

共通コーディングルール
1クラスにつき1ファイル
1クラスは1つの責務を持つ
1関数につき1処理
なにかあたらしいものを追加したときには(機能単位)githubへアップロード、git管理する

定期的なコミット、githubアップロード
ブランチは作業開始時に分けて終了してテストできたらそれをメインにする
GUIアプリケーションとし、プレイ対象も主にGUIアプリケーションとする
ある程度まともにプレイすることも出来るしアホな純粋なLLM(localのollamaなので当然アホ)に近いプレイさせてもいい
