# 操作候補統合

`CandidateMerger` はAutomation由来の `ActionCandidate` と、OCR / 画像認識由来の共通中間表現 `DetectedElement` を統合し、実行候補 `ActionCandidate` を生成する。重複判定は同一ID、矩形IoU、近接座標に加えて正規化textを利用し、重なる別ラベルUIを誤って同一候補へ潰さない。textを持たない画像primitiveは空間一致を主EvidenceとしてOCR/Automation候補へ統合する。

優先順位は Automation > OCR > image とし、同一source group内の重複はconfidenceが高い候補を残す。`DetectedElement` は `bbox / source / confidence / text / element_type` を保持するため、認識器固有出力をActionへ直結させずに統合できる。既存の `image_candidates` は互換入力として扱い、統合後の候補は `ActionEvaluator` が安全性を検査する。
