# 設定永続化

`ConfigStore` はProvider、モデル、Endpoint、人格、目的を `config.json` に保存する。未作成時は安全なローカル規則設定を返し、未知の設定キーは無視する。

`ExecutionHistory`、`HistoryStore`、`KnowledgeStore` のJSON配列保存は、同じディレクトリに一時ファイルを書き、flush・fsync後に置換する。書込や置換に失敗した場合は既存ファイルを維持し、一時ファイルを可能な範囲で削除する。不正JSONや配列以外の内容は追記時にエラーとして報告し、上書きしない。この方式は一時ファイルの完成前にプロセスが終了した際の破損を防ぐが、複数プロセスからの同時追記を直列化するものではない。
