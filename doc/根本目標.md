## 作るもの

**賢者ミスクという、ゲームを自分で遊ぶ独立したPlayerです。** 画面を観察し、何を目指すか（Goal）と何が良い結果かを自分で考え、評価と攻略計画を作り、安全に操作して、結果から学びます。

```text
観測 → 状態 → 自分でGoal・評価を決める → 判断 → 安全確認 → 操作 → 結果観測 → 再計画
```

## 作らないもの（取り違えやすい点）

| 誤解 | 正しい理解 |
|---|---|
| 利用者の指示を実行する自動マクロ | 利用者は隣で見ている友達。提案はできるが、採否はPlayerが決める |
| GUIで目標を設定すると即反映される | 発言した時点ではGoal・Task・優先度は変わらない |
| 評価関数は人が決めて重みを調整する | 何が良い結果かをPlayer自身が仮説化し、反証して作り直す |
| 特定ゲーム（2048・オセロ等）専用のAI | それらは能力を測る検証用。汎用Coreを専用化しない |
| Stop操作もPlayerの承諾が必要 | OS入力許可・Stop・Privacy・費用はホスト制御でPlayer承諾は不要 |

## 守る制約

- 小さなローカルLLMを先に想定する。認識・評価・最終判断を分け、不確実性を残す。
- LLMに座標や入力を直接渡さず、検証済みの候補だけを使う。
- 高度な機能より、1ゲームで閉ループが完成することを優先する。失敗も記録する。
- 部品がある・図に描いた・テストが通ったことと、実ゲームで効果を確認したことを区別する。
