# 画像解析

`FrameAnalyzer` はBGRAフレームを `ScreenObservation` へ変換する。平均RGB、平均輝度、完全一致用SHA-256シグネチャに加え、外部依存なしの64bit dHash（`perceptual_hash`）を抽出する。`BrightRegionDetector` は明るい連結領域を低confidenceの `DetectedElement` として返し、`bbox / source / confidence / element_type` を認識共通形式で保持する。`FrameAnalyzer` はこの共通形式を `detected_elements` に保存し、既存Pipeline互換の `image_candidates` も派生生成する。OCRは任意Recognizerがある場合だけ結果を追加する。

`ScreenSimilarity` は同一画面・寸法の観測をdHashで比較し、`similarity`、`difference_ratio`、`identical` / `nearly_same` / `partially_changed` / `changed` を返す。dHashがない旧観測はSHA-256、続いてOCRテキストの完全一致へ後方互換フォールバックする。`LoopGuard` はこの類似度を使い、ほぼ同じ画面の反復も停止対象にする。認識回帰にはfixture画像を利用し、画像由来Elementのbbox/sourceと互換候補生成を固定する。
