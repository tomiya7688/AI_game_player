# 画像解析

`FrameAnalyzer` はBGRAフレームを `ScreenObservation` へ変換する。平均RGB、平均輝度、完全一致用SHA-256シグネチャに加え、外部依存なしの64bit dHash（`perceptual_hash`）を抽出する。BrightRegionDetectorは明るい連結領域を低信頼度の境界済み候補として追加し、OCRは任意Recognizerがある場合だけ候補とテキストを追加する。

`ScreenSimilarity` は同一画面・寸法の観測をdHashで比較し、`similarity`、`difference_ratio`、`identical` / `nearly_same` / `partially_changed` / `changed` を返す。dHashがない旧観測はSHA-256、続いてOCRテキストの完全一致へ後方互換フォールバックする。`LoopGuard` はこの類似度を使い、ほぼ同じ画面の反復も停止対象にする。画像候補は設定済み候補・OCR候補より後に統合される。
