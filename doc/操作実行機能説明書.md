# 操作実行

`ActionExecutor` は安全評価済み候補の実行境界を提供する。既定は `dry_run=True` で、選択結果だけを返してOS入力を行わない。実入力は別Executorとして明示実装し、誤って有効化されないよう未実装時はエラーにする。

実入力を開始する前に対象ウィンドウが選択されていることを確認し、WindowsではHWNDが有効かを再検証する。`window_message` はクリック／キー入力を選択中のHWNDへ送り、カーソル移動やグローバルマウス入力へフォールバックしない。対象が未選択または失効していれば、設定保存や判断・実行を開始せずエラーにする。

利用者が実行中に停止を要求すると、`RunController`は現在の実行世代を無効にする。`DecisionPipeline`はその停止状態と実行世代を`ActionExecutor`へ渡し、Windows入力のキー保持または待機を中断させる。キー保持の中断時、`WindowsInputExecutor`は押下中のキーを解除してからstepを終了する。停止後にOllamaの推論応答が返っても、その古い応答は新たな実入力へ進まない。
