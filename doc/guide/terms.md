# 用語集：難しい言葉を日常の言葉に直す

[全体案内へ戻る](README.md) ｜ [詳しい資料の書き方](writing_rules.md)

| 言葉 | ここでの意味 |
|---|---|
| WGC／GDI | Windowsで画面を取得する方式。WGCは新しい画面取得の仕組み、GDIは従来の描画機能を使う仕組み。このアプリは利用条件に応じて方式を選びます。 |
| 画面観測 | 今のゲーム画面を取得し、いつ・どの画面を見たかも含めて扱うこと。 |
| 操作候補 | 「この位置を押す」「このキーを入力する」など、次にできそうな操作の案。候補になっただけでは実行できません。 |
| 候補の評価 | 操作候補を比較し、使ってよい候補を絞る処理。評価点が高いことと実行許可は別です。 |
| OCR（文字認識） | 画像に写っている文字を読み取る処理。読めない画像や誤読もあります。 |
| 確信度 | 処理がどれくらい強い根拠を得たかを表す値。必ずしも「正しい確率」ではありません。 |
| 判断材料 | 現在の画面、許可候補、目的、前回の操作結果など、次の操作を選ぶためにまとめた情報。 |
| プロバイダー | 判断の依頼を受け、規則や外部サービスなどの仕組みで回答する接続用の部品。 |
| ローカル規則 | あらかじめ決めた計算や条件で操作を選ぶ方法。判断用の学習済みモデルは不要です。 |
| 学習済みモデル | 学習によって作られた推論用データ。モデル名が設定欄にあるだけでは実行された証拠になりません。 |
| Ollama | モデルを動かすためのサービス。Ollama自身はモデル名ではありません。 |
| Tesseract | 画像の文字を読むための仕組み。言語データや実行環境がなければ、設定だけでは読み取れません。 |
| 実行基盤 | モデルや処理を実際に動かすソフトウェア・計算機の仕組み。 |
| オーケストレーター | どの処理やモデルをどんな順序・条件で使うかを選ぶ調整役。安全確認そのものではありません。 |
| 確認運転（dry-run） | 操作を選んだ記録は残すが、ゲームへ実際の入力を送らない運転。 |
| 実入力 | キーボードやマウスなどの操作をゲームへ本当に送ること。明示的な許可が必要です。 |
| 安全確認 | 候補、画面の新しさ、停止状態などを確かめ、危険な操作を拒否する仕組み。 |
| 結果評価 | 入力したかどうかでなく、その後の画面がどう変わったかを見て、前回操作の結果を調べること。 |
| 記録 | 何を観測し、どう判断し、入力したか・拒否したかなどを後で追える形で残すこと。 |
| 学習用データ | 将来モデルを学習・評価するために整えた材料。データを作っただけでモデルが自動更新されるわけではありません。 |
| ネイティブ処理 | この資料では主にC++側の処理。使える部品があっても標準経路で使われるとは限りません。 |

**実装状態の言い分け**

- **部品がある**：コードを確認。
- **つながっている**：通常の実行経路から呼ぶことを確認。
- **実機で確かめた**：実際の環境で試し、記録を確認。
- **設計上の予定**：これから作る・調べるもの。上の三つへ読み替えません。

言葉の意味はページを開いたときにも説明します。用語集を読まないと入口を理解できない書き方は避けます。
