# Experience Training Dataset Builder

`ExperienceDatasetBuilder` は、Learning Capabilityが宣言するDataset schema/versionに従い、保存済みExperienceのEpisode列またはExperienceReaderからモデル用Training Datasetを作ります。学習処理自体は行いません。

## Experienceイベント形式

対象のEvent typeとpayloadは次のとおりです。共通で `input` と `target` が必要です。任意の `label_source`、`label_confidence`、`verified` を付けられます。

| Event type | Dataset sample type | 用途 |
|---|---|---|
| `decision.sample` | `decision.instruction_response` | Decision instruction / response |
| `ocr.correction` | `ocr.correction` | OCR input / corrected text |
| `ui.region.label` | `ui.region_class` | UI region / class |
| `embedding.example` | `embedding.example` | `relation` は `positive` / `negative` / `prototype` |
| `evaluator.sample` | `evaluator.calibration` | Evaluation evidence / target |

その他のpayload fieldは拒否します。対象外Event typeはDatasetへ変換しません。

## Label・Provenance・Privacy

- `label_source` は `human_correction`、`automatic_label`、`outcome_evidence`、`unattributed` のいずれかです。未指定の場合はExperience provenanceから導出し、それ以外は `unattributed` になります。
- confidenceはpayloadの `label_confidence`、次にExperience provenanceのconfidenceを使います。
- `verified=true` は明示されたhuman correctionだけに許可します。自動labelやoutcome evidenceをground truthとして格上げしません。
- 元Episode / Step / Event ID、model identity、provenanceを保持します。同一内容のsampleはSHA-256でdeduplicateし、全source referenceを保持します。
- Artifact本体は読み込まず参照だけを扱います。sensitive artifactは既定で除外し、`include_sensitive_artifacts=True` を明示した場合だけ参照を含めます。除外の有無はsampleに記録されます。

## 分割と保存

Sample fingerprint、seed、validation fractionからtrain/validationを決定するため、同じ入力と設定なら常に同じsplitになります。Datasetにはmodel identity、schema ID/version、source Episode IDs、split設定、sample一覧、content digestを含みます。`to_json` / `from_json` でcanonical JSONをexport/importし、import時にsample ID・split・全体digestを再検証します。
